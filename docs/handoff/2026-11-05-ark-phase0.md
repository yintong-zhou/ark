# Handoff — Ark Fase 0 (usage)

## Obiettivo

Ark è un'app desktop Windows (Electron + React + Tailwind + TS) che riunisce gli agenti di coding installati (Claude Code, Codex, OpenCode). La Fase 0 mostra a colpo d'occhio:
- il **contesto di ogni sessione aperta**, così l'utente decide da solo quando fare compact o handoff (verso il 40–50%);
- i **limiti di 5 ore e settimanali**, per capire quando fermarsi.

Ark si limita a mostrare i numeri: niente notifiche. Brief: `PROJECT.md`; regole di lavoro: `AGENTv2.md`; grafica: `brand-guidelines.md`.

## Cosa abbiamo provato che NON ha funzionato

- **Heredoc bash con `\\` o apostrofi.** Il tool Bash riduce `\\` a `\` (path Windows e regex rotti nei fixture/test) e va in errore di parsing con gli apostrofi (`isn't`). → Per i file con path Windows, regex con backslash o testo con apostrofi usare **sempre lo strumento Write**.
- **`npx tsx -e "import('./x.ts')..."` o `require` di moduli TS.** Funzioni undefined, oppure `ERR_REQUIRE_ASYNC_MODULE`. → Scrivere uno script `.mts` in `.tmp/` ed eseguirlo con `npx tsx .tmp/file.mts`.
- **`ConvertFrom-Json` su `~/.claude.json`.** Fallisce per chiavi duplicate. → Per account e config dir usare `claude auth status` (JSON).
- **`mergeWindow` che sceglie solo il `resetsAt` più tardo.** Una lettura vecchia di un rollout (reset +2 s di jitter) batteva quella fresca di app-server (8% invece di 18%). → Stessa finestra se i reset distano meno di 60 s, e vince la % più alta.
- **Tolleranza di 600 s per "stessa finestra".** Troppo larga, rompeva i test → 60 s.
- **Registrare l'IPC dopo `await claudeAuth()`.** Il renderer chiamava prima che i canali esistessero ("No handler registered"). → Gli handler si registrano subito, i path della status line sono una Promise.
- **`findGitBash` con `dirname(dirname(git))`.** Falliva quando `git` risolve a `...\Git\mingw64\bin\git.exe`. → `gitBashFromGit` risale fino a 3 livelli cercando `bin\bash.exe`.
- **Lo `SHELL` di Git Bash (`/usr/bin/bash`).** Non è un path Windows eseguibile. Nei test il `SHELL` ereditato nascondeva il bug della shell. → I test del wrapper girano senza `SHELL`; la shell giusta viene registrata al Connect.
- **`/usr/bin/time`.** Non esiste in questo Git Bash → per misurare usare `date +%s%N`.

## Problemi incontrati e come li abbiamo risolti

- **"Electron uninstall" a `npm run dev`.**
  - Causa: npm non ha eseguito il postinstall di Electron.
  - Fix: `node node_modules/electron/install.js` (scritto nel README).
- **TS6 rifiuta gli import CSS senza tipi.**
  - Fix: `/// <reference types="vite/client" />` in `src/renderer/env.d.ts`.
- **Warning ESM di Vitest.**
  - Fix: il config si chiama `vitest.config.mts`.
- **Lint React Compiler "impure function during render".**
  - Fix: `useState(() => Date.now())`.
- **Le installazioni npm di un CLI non partivano.**
  - Causa: `where` elenca prima lo shim npm senza estensione.
  - Fix: `pickExecutable` sceglie solo `.exe` / `.cmd` / `.bat`.
- **Lo storico datava le letture vecchie con "adesso".**
  - Fix: `recordAgent` / `recordSession` ricevono l'ora della lettura; le finestre scadute non vengono registrate.
- **Il wrapper poteva richiamare se stesso all'infinito.**
  - Fix: variabile d'ambiente `ARK_STATUSLINE_WRAPPER=1` nel figlio; al Connect, qualsiasi comando che contiene `statusline-wrapper.cjs` è considerato di Ark.

## Decisioni prese

- **Vista principale Compact (tabella)**, scelta dall'utente nel mockup. La Detailed resta come seconda modalità.
- **Niente notifiche**: solo visualizzazione (scelta dell'utente).
- **"Gestisci account" è in sola lettura**: mostra con quale account si è collegati. Scartato: account multipli e switch.
- **"Limite giornaliero"** = tacca del ritmo sulla barra settimanale. Scartata una quota giornaliera separata. Tacca del contesto fissa al 50%.
- **Status line di Claude Code:** un wrapper davanti alla status line dell'utente.
  - Trasporto: file drop in `<userData>/claude/sessions/<id>.json`. Scartata la porta HTTP: niente porta aperta, funziona anche ad Ark chiuso.
  - Il wrapper esegue l'originale nella **Git Bash** registrata al Connect, con fallback a `SHELL` esistente e poi cmd. Scartato cmd come default: Claude Code usa bash.
  - Runner: `node` se è nel PATH, altrimenti `Ark.exe` con `ELECTRON_RUN_AS_NODE=1`.
- **Codex:**
  - limiti e account da `codex app-server` (`account/rateLimits/read`, `account/read`); scartato il parsing di `codex login status`;
  - contesto dai rollout `~/.codex/sessions` in sola lettura, scansione delle cartelle data degli ultimi 8 giorni;
  - formula del contesto = Codex (baseline 12000), ricostruita senza il sorgente.
- **Sessioni:** inattive dopo 30 min (righe attenuate), fuori dalla tabella dopo 12 h, tenute 7 giorni. Storico in `history.jsonl` per 30 giorni, una riga ogni 5 minuti al massimo.
- **Interfaccia:**
  - sigle CC/CX/OC al posto dei loghi dei produttori;
  - UI in inglese;
  - verde acqua solo sui CTA (Refresh, Connect);
  - spazi invece di "·" tra i metadati;
  - "as of X ago" sui dati più vecchi di 15 minuti.
- **Esecuzione:** il piano è stato eseguito in modalità "diretta" (scelta dell'utente), con una sola revisione finale.
